# Homelab Infrastructure

This section documents the design, deployment, configuration, and maintenance of my cybersecurity homelab.

## Purpose

The homelab provides a controlled environment for developing practical cybersecurity skills through system administration, network security, security monitoring, penetration testing, and incident investigations.

## Technologies

- Proxmox VE
- OPNsense
- Wazuh SIEM
- Kali Linux
- Debian Linux
- Metasploitable
- Tailscale
