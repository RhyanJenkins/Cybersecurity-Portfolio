# Homelab Infrastructure

This section documents the design, deployment, configuration, and maintenance of my cybersecurity homelab.

## Purpose

The homelab provides a controlled environment for developing practical cybersecurity skills through system administration, network security, security monitoring, penetration testing, and incident investigations.

## Technologies

- Proxmox VE
- OPNsense
- Wazuh SIEM
- Kali Linux
- Debian Linux
- Metasploitable
- Tailscale

## Documentation

Projects in this section will cover:

- Physical and virtual infrastructure
- Network architecture and segmentation
- Firewall configuration and traffic management
- Security monitoring architecture
- Remote administration
- Troubleshooting and lessons learned

Detailed technical documentation will be added as projects are completed and reviewed for public release.
