# Project Evidence

This directory contains sanitized evidence supporting the technical findings documented in PRJ-001.

## Evidence Requirements

Each published artifact must:

- Relate to a documented validation activity.
- Have a unique evidence identifier.
- Include sufficient context to explain its relevance.
- Exclude sensitive live infrastructure details.
- Preserve a reference to the original evidence.
- Identify any redaction or modification performed.

## Evidence Naming Convention

Use:

`PRJ-001-VAL-###-E##-description.ext`

Example:

`PRJ-001-VAL-003-E01-firewall-log.png`

## Evidence Integrity

Original evidence is retained privately.

Where appropriate, SHA-256 hashes are recorded for original files before editing.

Sanitized copies are used for public GitHub documentation.

A sanitized copy is not represented as an unchanged original artifact.

## Current Status

Evidence artifacts will be added after verification and sanitization.
