# Cybersecurity Portfolio

Welcome to my cybersecurity portfolio! This repository documents my hands-on learning, technical projects, and practical experience across digital forensics, incident response, offensive security, and defensive security.

My focus is on understanding how systems operate, how attacks occur, how security events are detected, and how digital evidence can be analyzed to reconstruct activity.

## Areas of Interest

- **Digital Forensics:** Evidence collection, forensic analysis, artifact examination, and event reconstruction.
- **Incident Response:** Security investigations, log correlation, incident timelines, and threat analysis.
- **Offensive Security:** Authorized penetration testing, vulnerability assessments, and attack simulations.
- **Defensive Security:** Security monitoring, intrusion detection, firewall configuration, and system hardening.
- **Security Engineering:** Virtualization, network architecture, Linux administration, and security infrastructure.

## Cybersecurity Homelab

I maintain a virtualized cybersecurity homelab designed to provide practical experience with offensive and defensive security technologies.

The environment uses Proxmox VE to host systems for security monitoring, network defense, penetration testing, and controlled attack simulations.
