### CASE-001 | FTP Traffic & SIEM Visibility Investigation

**Category:** Incident Response / Network Security / Detection Analysis  
**Status:** Investigation Ongoing

An evidence-based investigation examining differences between OPNsense firewall visibility and Wazuh SIEM search results during controlled FTP connectivity testing.

**Documented observations:**
- Kali Linux successfully reached the target's FTP TCP port.
- OPNsense recorded permitted traffic between the testing and target systems.
- Searches in Wazuh did not identify a corresponding alert within the documented search criteria.
- The underlying cause of the visibility difference remains unverified.

**Investigative focus:**
- Firewall log examination
- TCP connectivity validation
- SIEM search and event correlation
- Evidence collection and documentation
- Identification of monitoring limitations

This case study distinguishes verified observations from investigative hypotheses. The available evidence does not establish successful FTP backdoor exploitation or a failure of Wazuh log ingestion.

**Technologies:** Kali Linux, Metasploitable 2, OPNsense, Wazuh, TCP/IP
