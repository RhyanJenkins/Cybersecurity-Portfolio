## Documentation Standards

When scripts or technical utilities are published, documentation will include:

1. **Purpose:** The problem the tool addresses.
2. **Environment:** Supported operating systems and prerequisites.
3. **Usage:** Commands, parameters, and examples.
4. **Validation:** Testing methodology and observed results.
5. **Limitations:** Known issues and unsupported conditions.
6. **Security:** Relevant permissions, risks, and safe operating practices.

Scripts will be reviewed before publication to prevent accidental disclosure of credentials, private infrastructure details, or other sensitive information.
